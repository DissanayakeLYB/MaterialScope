A **crystal** is a material whose atoms are arranged in a repeating pattern. The smallest repeating unit that captures the full symmetry of the pattern is called a **unit cell**.

<Callout type="info" title="Key idea">
  The unit cell is like a single tile in a bathroom floor: tile the whole floor
  with it, and you get the complete pattern.
</Callout>

## The seven crystal systems

Unit cells come in seven shapes, defined by their edge lengths (`a`, `b`, `c`) and the angles between them (`α`, `β`, `γ`):

| System       | Axes      | Angles                |
| ------------ | --------- | --------------------- |
| Cubic        | a = b = c | α = β = γ = 90°       |
| Tetragonal   | a = b ≠ c | α = β = γ = 90°       |
| Orthorhombic | a ≠ b ≠ c | α = β = γ = 90°       |
| Hexagonal    | a = b ≠ c | α = β = 90°, γ = 120° |
| Rhombohedral | a = b = c | α = β = γ ≠ 90°       |
| Monoclinic   | a ≠ b ≠ c | α = γ = 90°, β ≠ 90°  |
| Triclinic    | a ≠ b ≠ c | α ≠ β ≠ γ ≠ 90°       |
